# Unreal Engine 5.x Review Checklist

Version anchors (November 2026): **Unreal Engine 5.8** (released 2026-06-17), which Epic calls the
last planned major UE5 release. UE6 early access is targeted for late 2027, built around Verse and
Scene Graph; that is a planning concern, not a review finding. Read the engine version from the
`.uproject` `EngineAssociation` field.

## 1. Outdated APIs agents still write (A1)

| Stop | Use (UE 5.x) | Grep |
|---|---|---|
| Legacy input: `InputComponent->BindAxis/BindAction`, action/axis mappings in `DefaultInput.ini` | Enhanced Input: `UInputAction`, `UInputMappingContext`, `UEnhancedInputComponent::BindAction` (legacy input deprecated since 5.1) | `BindAxis\|BindAction\(\"` |
| Raw `UObject*` member properties | `TObjectPtr<T>` for `UPROPERTY` members | `UPROPERTY\([^)]*\)\s*\n\s*U\w+\s*\*` |
| PhysX APIs (`PxRigidActor`, `physx::`) | Chaos physics | `physx\|PxRigid` |
| Matinee | Sequencer | `Matinee` |
| Blueprint nativization settings | Removed in UE5; convert hot Blueprint logic to C++ by hand | `Nativiz` |
| `FTimerManager` lambdas capturing raw `this` without weak checks | `FTimerDelegate::CreateWeakLambda` / `CreateUObject` | `SetTimer\(.*\[this\]` |

## 2. Agent mistakes that compile, or almost compile (A2 / G-checks)

- **Missing `UPROPERTY()` on UObject pointers.** The garbage collector does not see the reference;
  the object can be collected while still in use. CRITICAL when on gameplay objects.
- **`ConstructorHelpers::FObjectFinder` outside constructors.** Asserts at runtime.
- **Invented signatures.** `SpawnActor` overloads with wrong parameter order; `UGameplayStatics`
  functions that do not exist; `FMath` helpers borrowed from Unity names (`FMath::MoveTowards`).
  Grep the project and plugins; otherwise mark Verify with the header to check.
- **Ticking everything.** Template constructors set `PrimaryActorTick.bCanEverTick = true`; actors
  that do nothing per frame should disable Tick or use timers.
- **Per-tick searches.** `UGameplayStatics::GetAllActorsOfClass`, `TActorIterator`, `Cast<>` chains,
  `FindComponentByClass` in `Tick` (G2).
- **String work in Tick.** `FString::Printf`, `*FString` conversions, `GEngine->AddOnScreenDebugMessage`
  without `#if !UE_BUILD_SHIPPING` guards.
- **Hard references in Blueprints and DataAssets** pulling huge dependency chains into memory; prefer
  `TSoftObjectPtr` / `TSoftClassPtr` and async loading.
- **`check()` for recoverable conditions.** Crashes shipping builds; use `ensure()` or explicit
  handling where recovery is possible.
- **Delegates bound to destroyed objects.** Use `AddUObject` / `AddWeakLambda`; unbind in `EndPlay`.

## 3. Replication (A6)

- `UFUNCTION(Server, Reliable)` called every tick (reliable buffer overflow; use Unreliable for
  high-frequency input).
- Server RPCs applying client-provided damage, score, currency, cooldowns or positions without
  server-side recomputation or validation.
- Replicated properties written on clients (they will be overwritten, or worse, trusted by local
  logic). Check `HasAuthority()` guards.
- `GetLifetimeReplicatedProps` missing `DOREPLIFETIME` for new replicated fields, or replicating
  far more than needed.
- Gameplay Ability System: abilities granted or activated client-side without server confirmation.

## 4. Project and file hygiene (A8)

| Item | Rule |
|---|---|
| `.uasset` / `.umap` | Binary; must be in Git LFS (or Perforce). Review through the editor diff tool; a text diff tells you nothing |
| `Intermediate/`, `Saved/`, `DerivedDataCache/`, `Binaries/` | Never committed (except deliberately shipped plugin binaries) |
| `Config/Default*.ini` | Review every changed key: renderer, physics, input, networking, packaging |
| `*.Build.cs`, `.uplugin`, `.uproject` plugin list | New modules and plugins are new dependencies (A3); experimental plugins enabled in shipping configs are MAJOR |

## 5. MCP and AI Assistant changes

UE 5.7 added an experimental in-editor AI Assistant that can generate C++. UE 5.8 ships an
experimental Unreal MCP plugin: editor-only, served on `127.0.0.1:8000/mcp`, with no
authentication. Community servers (for example chongdashu/unreal-mcp) cover Blueprints and actors.
For reviews this means:
- MCP-made Blueprint and level changes arrive as binary `.uasset` churn; ask for an editor diff
  screenshot or a description of each changed asset in the PR;
- C++ generated by the assistant gets the full A1-A12 audit;
- the MCP endpoint must never be exposed beyond localhost (it is unauthenticated), and it is not a
  CI service.
